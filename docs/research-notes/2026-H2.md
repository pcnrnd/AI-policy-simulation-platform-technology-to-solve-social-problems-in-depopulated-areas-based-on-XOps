## 2026-07-09~10 — xops-service 구현 (DataOps 가상화 API + MLOps)

- **수행 기간**: 2026-07-09 ~ 07-10 / 기록일: 2026-09-01
- **목표**: H1 클라이언트 시뮬레이션(`dataopsApi.js`)을 FastAPI 백엔드로 포팅 —
  "저장소를 직접 노출하지 않고 메타데이터+API로 추상화"를 서버에서 성립
- **수행 내용**:
  - DataOps: `MetadataCatalog`(mock 시드 + 사용자 등록) → Adapter 결정 → SQL/MQL 생성
    (range 자동 주입) → 안전 검증(`safety.py`) → `buildApiResponse` 계약 응답.
    JWT(HS256, stdlib)·OAuth2 발급, 전 CRUD `data:read`/`data:write` scope 게이트
  - MLOps 모니터링: 6대 지표(혼동행렬 기반)·드리프트 PSI/KL·이상치 Z-score/IQR·SHAP
    (미설치 시 순수 파이썬 fallback)를 **실계산**. 드리프트 감지 → 재학습 이벤트 자동 발화
  - MLOps 오케스트레이션: `queued→…→succeeded/rejected/rolled_back` 상태머신,
    EventBus debounce, canary→full 배포·latency 임계 자동 롤백
  - 프론트 3페이지(DataOps·Monitor·Orchestrator) mock 제거·실 API 연동,
    SQLite(WAL) 영속화(사용자 소스·모델 버전·실행 이력), prod 토큰 게이트, Docker 패키징
- **결과**: 테스트 79건 / 커버리지 95% (게이트 80%)
- **근거**: 커밋 `fede6de`·`54d58c1`·`64adc72`·`27b7c5c`·`b06bba2`·`4fda93f`·`5d22a9f`·

## 2026-08-31 — 실 저장소 실행 계층(읽기) + 카탈로그 주입 차단

- **수행 기간**: 2026-08-31 / 기록일: 2026-09-01
- **수행 내용**:
  - `QueryAdapter` seam을 실제 질의 계층으로 채움: `backends.py`(psycopg — PostgreSQL·
    PostGIS·TimescaleDB 공용 / pymongo), 드라이버 지연 import·미설치 시 degrade.
    화면 표시 SQL과 실행 SQL이 동일하고, 총계는 같은 WHERE의 COUNT(*)로 실측.
    표시용 MQL 문자열을 되파싱하지 않고 같은 입력에서 드라이버용 필터 dict를 별도 생성
  - compose에 실 저장소 3종 편성(postgis 이미지가 PG+PostGIS 겸용, timescale·mongo 분리),
    initdb DDL·최소 시드를 카탈로그 metadata_schemas와 1:1로 맞춤, healthcheck 게이트
  - **보안 정정(기록 가치)**: `POST /dataops/catalog`가 무인증 개방이고 등록된
    object·컬럼명·range가 생성 SQL에 그대로 조립됨을 확인 — 실 저장소가 붙는 순간
    UNION·불리언 주입이 성립(수정 전 4개 페이로드 등록 201 + 조회 200 재현).
    3중 방어(등록 경계 422 / 실행 경계 `assert_safe_schema` 400 / 생성기 이스케이프)로 차단.
    UNION 부분 문자열 블록리스트는 정상 식별자(credit_union_members) 오탐 때문에 채택하지
    않고 식별자 allowlist로 근본 차단
  - 콘솔 코드페이지(cp949)로 한글 로그 레코드가 유실되던 문제 수정
- **결과**: 테스트 141건(어댑터 24건 추가) → 172건(주입 31건 추가) / 커버리지 96.85%
- **근거**: 커밋 `8a6bb48`·`ada7852`·`0d88cf1`·`18c3633`

## 2026-09-01 — 쓰기 경로 관통·실 공공데이터 적재·compose 완전체 기동

- **수행 기간**: 2026-09-01 / 기록일: 2026-09-01
- **수행 내용**:
  - **쓰기 실행**: POST/PUT/PATCH/DELETE를 실 저장소에 관통. 값은 SQL 리터럴 조립 없이
    전부 드라이버 파라미터 바인딩(`build_write_sql` — 표시용 `?` SQL을 되파싱하지 않고
    같은 입력에서 별도 생성). 실행 조건 가드: 본문 값 없는 쓰기·filter 없는
    PUT/PATCH/DELETE는 실행하지 않고 결정적 스텁 유지(데모 클릭의 범위 전체 덮어쓰기 차단).
    쓰기 본문은 읽기 주입 차단과 같은 실행 경계에서 검증 — 컬럼명 스키마 대조,
    스칼라 강제(Mongo `$set` 연산자 주입 차단), 길이·NUL 상한
  - **실데이터 2건 수집·적재**(로그인·API키 없는 공개 원본만 사용):
    ① 전국 시군구 행정구역경계 GeoJSON 251개(통계청 2013, southkorea-maps 재배포) →
    PostGIS `geo_admin_boundary`(ST_Multi 정규화, ST_Area 실측 남원 745km²·신안 705km²),
    ② 남원시 사회복지시설현황 11행 + 신안군 장애인복지시설현황 6행(공공데이터포털
    15094099·15114967, CP949→UTF-8 변환만) → `tb_welfare_facility` 17행.
    카탈로그 ds_08·ds_09 등록, 원본은 `platform/data/real/` 커밋(멱등 적재기 동반).
    남원·신안 우선하되 경계는 전국 보존(벤치마크 원칙)
  - **compose 완전체 기동 검증**(이미지 빌드 포함): 컨테이너 경유 실측 — 실 저장소 3종
    `source_kind=database` 조회, 쓰기 왕복(SQL 17→18→17행 / MQL POST·PATCH·DELETE 각
    affected 1), nginx 프록시 카탈로그 9종. 호스트 포트 점유 환경 대응으로
    `XOPS_HOST_PORT`/`XOPS_FRONTEND_HOST_PORT` 오버라이드 도입(기본값·내부 계약 불변)
- **결과**: 테스트 172 → 183건 / 커버리지 96.4%, 문서 현행화(§11·§12 후속 목록 해소)
- **근거**: 커밋 `892f5a5`·`e8c1b9b`·`6bf4478`·`0da15aa`, `platform/data/real/README.md`
