## 작성 규약

1. **수행일 / 기록일 분리 표기.** 본 노트는 2026-09-01에 git 이력·설계 문서·테스트 결과로부터
   소급 재구성했다. 각 엔트리의 "수행 기간"은 커밋 시점 기준이며, 기록일과 다름을 명시한다.
2. **모든 주장에는 근거를 단다.** 커밋 해시, 문서 경로, 테스트 수치 중 하나 이상.
   근거가 저장소 밖(회의록 등)에 있으면 `[보강 필요: ...]`로 표시하고 지어내지 않는다.
3. **엔트리 골격**: 수행 기간 → 목표 → 수행 내용 → 결과(정량) → 의사결정과 근거 → 잔여 과제.
4. 본 노트는 **공인 전자연구노트가 아니다**. git 커밋 이력이 수행 시점의 객관 근거 역할을 하며,
   공식 증빙 용도로 쓸 경우 과제 관리 기관의 연구노트 규정을 별도 확인한다.
5. **범위.** 이 노트는 플랫폼(백엔드 `platform/backend/xops-service`·프론트 `platform/frontend`·
   저장소 인프라)의 기술 연구를 다룬다. `cert/`(인증 시험 대응)와 2024–2025 구간
   (차트 성능 실험, Airflow/MLflow/DataHub/Qdrant 스택, standard_editor 데이터 버전관리 앱)은
   별도 관리 영역 또는 후속 소급 대상으로 본 노트 범위 밖이다.
6. **경로 표기.** 본문은 수행 당시 경로를 유지한다. 현재 위치 대응은 아래 표로 읽는다.

| 노트 표기 | 현재 위치 | 비고 |

| `decline_poc/` | `decline_poc/` (참조 스냅샷) | 2026-07-06 재편 때 `platform/frontend/`로 이식·계승 |

## 2026년 기술 흐름 (요약)

```
2026-H1                          2026-H2
decline_poc SPA 프로토타입        platform 공식화(frontend 이식 + backend 3서비스 골격)
6화면·mock 시드·RICE·시뮬레이션    xops-service: DataOps 가상화 API + MLOps 모니터링·오케스트레이션
                                 재학습 실물화(릿지+LOO) → 실 저장소 3종 연동(읽기→쓰기)
                                 실 공공데이터 적재(경계 251·복지시설 17) · compose 완전체 기동
```

핵심 설계 불변식(H2 전 기간 유지): **저장소는 직접 노출되지 않는다** — 모든 데이터 접근은
메타데이터 카탈로그 → Adapter → 안전 검증(식별자 allowlist·파라미터 바인딩) → 표준 REST 응답을
거치고, 실 저장소가 없어도 같은 응답 계약이 성립한다(In-Memory degrade).
