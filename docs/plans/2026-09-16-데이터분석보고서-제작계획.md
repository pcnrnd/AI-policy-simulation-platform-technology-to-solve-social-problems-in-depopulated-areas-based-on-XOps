## 5. 이미지 파이프라인

**본문 MD가 텍스트·표·캡션의 정본이며 본문 전체를 이미지로 바꾸지 않는다.**

| 종류 | 생성 경로 | 편집가능 소스 보존 |
|---|---|---|
| 도식 | MD/Mermaid 설계 → 편집가능 **PPTX 도형** → PNG | `.mmd` + `.pptx` |
| 분석 차트 | 고정 데이터(CSV) + 재생성 스크립트 → PNG | `.csv` + `.py` (편집가능 차트가 필요하면 원본 데이터가 연결된 PPTX도 함께 보존) |
| 원천 캡처 | 필요 시에만 | 원본·출처·촬영시점 기록 |

동일 PNG를 MD에서 **상대경로**로 참조하고 같은 PNG를 Word에 삽입한다. PDF는 완성 Word에서 내보낸다.

`figures.json` 항목: `id / 제목 / 근거데이터 / 스크립트 또는 PPTX슬라이드 / png_sha256 / 캡션 / 삽입위치`.
**PPTX나 근거 데이터가 바뀌면 PNG → Word → PDF를 함께 재생성**하고 대장의 해시를 갱신한다.

해상도·가독성은 **최종 인쇄 크기 기준**으로 확인한다: 한글 글꼴 깨짐, 범례, 축 단위, 잘림.
